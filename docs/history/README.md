# Documentation history

This directory preserves long-form development history that is useful for
forensics but is not the current source of product behavior or release status.

- `SESSION_LOG.md` records historical implementation sessions and their
  verification notes.
- `../RELEASE_NOTES.md` is the current release-level change record.
- Git history is the authoritative record of file changes.

Historical entries can contain paths that were correct when the entry was
written. Do not rewrite those paths unless the historical statement itself is
incorrect.
