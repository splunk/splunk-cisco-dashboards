# Security Policy

## Supported Versions

Security reports are evaluated against the current repository code. Include the exact version, build, or commit for any affected release. Fixes for earlier releases are assessed case by case.

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in public issues, discussions, pull requests, or support forums.

For vulnerabilities in this repository, use GitHub's **Report a vulnerability** option on the Security tab when it is available. If you do not see that option, open an issue asking the maintainers for a private reporting channel. Do not include vulnerability details in that public request.

For vulnerabilities affecting a Cisco product or service, contact the Cisco Product Security Incident Response Team at [psirt@cisco.com](mailto:psirt@cisco.com).

Include the affected version, build, or commit; the potential impact; and enough sanitized detail to help reproduce the issue. Do not include credentials, customer data, access tokens, or sensitive production configuration.

Please allow time for coordinated investigation and remediation before publicly disclosing a suspected vulnerability. No response or remediation timeline is guaranteed.
