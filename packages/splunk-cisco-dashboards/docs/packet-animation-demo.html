Packet animation demo

What the small filled circles should look like on your map

Each row below renders a single bezier path (the line) and 3 small filled circles that slide end-to-end along it on a continuous loop. This is exactly the same SMIL <animateMotion> + <mpath> pattern the production LinkPacketLayer uses. If your dashboard's map shows the marching dashes but not these dots, something in the rendering stack is clipping the dots — open this file as a sanity check that the pattern itself is supported in your browser.

Reading guide. On each row you should see (a) the line itself rendered as a series of dashes that march along the line in one direction (faster + glowing on the critical row), and (b) three small filled circles also moving along the line, but as independent dots that you can visually pick out from the dash flow. Those dots are the "packets". On the production dashboard map the line is a curved bezier between two map markers, but the rendering pattern is identical.

How to open this file. Either double-click it in Finder, or run open packages/splunk-cisco-dashboards/docs/packet-animation-demo.html from the repo root.
